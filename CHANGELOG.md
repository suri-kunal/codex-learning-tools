# Changelog

All notable changes to this project will be documented here.

## 1.0.0 - 2026-09-19

- Added free-form, single-select, and multi-select question popups.
- Added graded quizzes with “I don't know” and immediate feedback.
- Added opt-in, session-scoped Markdown logging through Codex hooks.
- Added portable Agent Plugins manifests and Codex compatibility manifests.
- Added a bundled MCP server for dependency-free installation.
