## Original inspiration

This repository was created to make the core interactive-learning workflow from [Amos Blomqvist's `learn`](https://github.com/amosblomqvist/learn) usable in Codex.

The original `learn` project is a personal AI learning system built as a Pi configuration. In particular, it demonstrated a cohesive workflow combining:

- an ungraded question popup;
- graded quizzes with immediate feedback; and
- session-linked Markdown logging.

Codex Learning Tools independently implements those ideas for Codex using MCP form elicitation, Codex plugin manifests, and lifecycle hooks. It is a focused Codex adaptation rather than a complete copy of the upstream Pi configuration, and it is not an official release of or affiliated with the upstream project.

Credit for the original `learn` project and its learning-system design belongs to **Amos Blomqvist**.
